# ISO Coverage Matrix — Cumplify.ai Master Table

This is the authoritative clause-by-clause coverage map for the Cumplify.ai Integrated Management System (IMS) across all three standards. Every sub-clause in the canonical spine (clauses 4–10) is represented, with its owning Cumplify module, owning Bedrock agent, and coverage status.

**Coverage status legend:**
- **FULL** — clause owned by an EXISTING module + EXISTING (built, PHASE-14) agent.
- **PARTIAL** — clause owned by an EXISTING module but the primary owning agent is NEW (roadmap), or clause split across an existing + roadmap agent.
- **ROADMAP** — clause owned by a NEW module and/or exclusively NEW (roadmap) agent(s).

Existing agents (built): ControlTower, DocStudio, LeadAuditor, CAPAGuru, RecordsVault, ISO9001 Domain Guru, ISO14001 Domain Guru, ISO45001 Domain Guru. All other agents are roadmap.

**Notes on status assignments:**
- **FULL** clauses are served today by an existing module and an existing (built, PHASE-14) agent: DocStudio (M1: 4.3, 5.2, 7.5, and 9001 operational clauses 8.2/8.3/8.5/8.6), ControlTower (4.4, 5.1, 5.3), RecordsVault (7.1 / 7.1.5), LeadAuditor (9.2 all 3), CAPAGuru (8.7, 10.1, 10.2, 10.3).
- **PARTIAL** — ISO 45001 clause 10.2 Incident, nonconformity and corrective action is chained NCTriage/IncidentInvestigator (roadmap) → CAPAGuru (existing); the incident-specific front end is roadmap while corrective-action closure runs on the existing CAPAGuru path, so the clause is transitional rather than fully built.
- **ROADMAP** clauses depend on a new module (M6–M13) and/or a roadmap agent (RiskSentinel, AspectWarden, HazardScout, IncidentInvestigator, LegalLedger, ObjectiveTracker, ReviewOrchestrator, ContextCartographer, SupplierScout, CompetenceKeeper, EmergencyPlanner, WorkerVoice).
- The three ISO Domain Gurus (ISO9001 / ISO14001 / ISO45001) and ComplianceCopilot provide advisory Q&A across all clauses in their respective standards and are not listed as primary clause owners in this matrix (advisory, not system-of-record).
