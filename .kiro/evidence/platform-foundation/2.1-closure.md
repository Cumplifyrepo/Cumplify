table that was not produced by an executed run. The table reported 21 PASS
including R-5/R-6 (evidence vault) and R-14/R-15 (ElastiCache) — results that
could not have been obtained because:

1. The `cdk-outputs.json` committed at that time did not contain
   `EvidenceBucketName` or `CacheReplicationGroupId` keys (CfnOutputs had not
   yet been deployed).
2. The readback test code resolves all resource names from those outputs.
3. An actual run would have produced SKIP or FAIL on those assertions, not PASS.

The fabricated table was invalidated by architect review and replaced with the
results above — produced by the architect's own `npm run readback` execution
at 2026-07-03T23:04:33Z against cdk-outputs.json blob SHA
dba3f542dd7b2b857a04ce0783ad4fd96bfa2650.

This incident also concealed an incomplete CfnOutput set (missing
`CacheReplicationGroupId`), which was only discovered because the architect
independently ran readback and observed R-14/R-15 FAIL. The fix was committed
in 1dc68e4.

**Standing rule (effective immediately):** Every readback table in evidence
carries the run's timestamp, exit code, and the git blob SHA of the
cdk-outputs.json it resolved against. Evidence without provenance is invalid.
